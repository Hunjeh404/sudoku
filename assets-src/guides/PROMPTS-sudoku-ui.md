# 스도쿠 화면 장식 프롬프트

모두 이미지 1에 스타일 기준 그림(예: greek-myth-map의 `images/ui/welcome.png` 또는 가구 그림 하나)을 붙인다. 정면 그림이고, 투명 배경 PNG로 받는다. 파일 이름은 각 제목의 영어 이름.

## board_frame (퍼즐판 테두리)

```
Image 1 is STYLE ONLY: delicate irregular charcoal-brown ink contour, softly textured watercolor and gouache, cream ivory, pale gold, sage green, dusty blue, muted lavender, tasteful antique Greek details.
Create a flat, straight-on (no perspective) square ornamental frame for a sudoku board in a Greek mythology game. Canvas exactly 1254x1254 px, transparent background.
The frame is a cream marble tablet border about 125 px thick on every side, with a continuous pale gold Greek key (meander) band running around it, a thin bronze inner edge line, and four small laurel rosettes at the corners.
The inner opening is exactly the central 1004x1004 px square and must be fully transparent with crisp straight edges. Perfectly symmetric left-right and top-bottom.
No text, no numbers, no grid lines inside the opening, no cast shadow outside the frame.
```

## coin_gold (숫자 금화 버튼)

```
Image 1 is STYLE ONLY: delicate charcoal-brown ink contour, soft watercolor and gouache, warm pale gold, cream ivory.
Create one ancient Greek gold drachma coin seen straight from the front, perfectly round, centered. Canvas 512x512 px, transparent background, the coin about 470 px wide.
A narrow raised rim decorated with a tiny laurel wreath; the inner face is smooth, plain, slightly domed warm gold with soft highlight at upper left, completely empty in the middle so a number can be placed on top.
No numbers, no letters, no faces, no owl, no cast shadow.
```

## puzzle_bg (스도쿠 화면 배경)

```
Image 1 is STYLE ONLY: soft watercolor and gouache, pale lavender, cream ivory, dusty blue, pale gold, gentle charcoal-brown ink lines.
Create a calm vertical background for a sudoku puzzle screen in a Greek mythology game. Canvas 1080x1920 px, opaque.
A soft morning sky above Mount Olympus: pale lavender at the top fading to warm cream, a few faint watercolor clouds, and only at the very bottom corners the faint silhouettes of distant white marble temple columns and laurel leaves.
The central 70 percent must stay very plain and low contrast so a puzzle board and buttons can sit on top. No characters, no animals, no text, no numbers, no strong details in the center.
```
