# 올림포스 집·정원 타일 11종

**11종 생성 및 수정본 묶음입니다. 규격 미충족 항목이 남아 있어, 전 항목을 그대로 교체하는 최종 규격본은 아닙니다.**

원본 PROMPTS-tiles.md의 지시대로 정면/상면 평면 그림을 제작했습니다. 게임의 기울이기·쿼터뷰 변환은 코드에서 처리해야 합니다. 생성 원본 PNG는 기계적 리사이즈·워핑·가장자리 합성 없이 보존했습니다.

## 구성

- images/tiles/: PNG 11장
- guides/: 제공받은 가이드 11장
- PROMPTS-tiles.md, tile-spec.json: 제공받은 지시서·규격 원문
- generation-prompts.json: 최초 및 채택한 수정 프롬프트
- asset-manifest.json: 실제 크기, 투명도, 비율, 해시, 연결부 수치

## 확인 결과

11장 모두 정상 PNG로 열리며, 울타리 1장은 투명도 0~255, 나머지 10장은 완전 불투명입니다. 9장은 요청 가로세로 비율에 맞습니다. 원문의 “크기가 조금 달라도 괜찮지만 가로세로 비율은 지켜야 한다” 조건을 적용했으며, 크기만 다른 항목을 비율 실패로 판정하지 않았습니다.

**floor_edge와 garden_edge는 요청 4:1 대신 3:1로 출력되어 비율 조건을 충족하지 못했습니다. 재생성 후에도 남은 차이입니다.**

## 개별 확인 및 남은 수정

- **floor_slab_a**: 연보라 무늬를 줄인 수정본. 테두리 폭이 목표 28px의 비율보다 두껍습니다.
- **floor_slab_b**: 따뜻한 크림색과 옅은 금빛 무늬로 수정. 테두리 폭은 정밀 규격 보정이 필요합니다.
- **floor_slab_c**: 연한 푸른 얼룩 중심으로 단순화. 테두리 폭은 정밀 규격 보정이 필요합니다.
- **wall_section**: 정면, 상단 물결 4회 반복. 밴드 높이와 좌우 연결부는 정확한 가이드 정합 미확정.
- **pillar_capital**: 네 줄 홈과 간소한 소용돌이 장식으로 수정. 몸통과 홈 위치·너비·색의 정밀 연결은 추가 보정 필요.
- **pillar_shaft**: 홈의 위아래 마감선을 제거하여 세로로 이어지게 수정. 끝단 색상은 완전 동일하지 않습니다.
- **pillar_base**: 정방형과 네 줄 홈, 단순 몰딩으로 수정. 몸통과 경계 맞춤은 추가 보정 필요.
- **floor_edge**: 불필요한 장식 제거. 요청 4:1과 달리 실제 3:1이므로 필수 규격 미충족.
- **grass**: 위에서 본 잔디. 반복 시 무늬의 반복성과 경계 색상 차이 재검토 필요.
- **garden_edge**: 잔디·흙·돌 구성. 요청 4:1과 달리 실제 3:1이므로 필수 규격 미충족. 상단 풀 주변 밝은 빈틈도 확인 필요.
- **garden_fence**: 실제 투명 PNG. 기둥 2개와 연결 난간. 하단 투명 여백이 남아 받침대의 바닥 밀착 좌표가 지시서와 다릅니다. 레일 두께 및 연결부 정밀 수정 필요.

## 반복 연결 검수

벽·기둥 몸통·바닥 앞면·잔디·정원 앞면·울타리를 반복 배치한 검사 화면을 확인했습니다. 기둥 몸통의 닫힌 홈 등 큰 구조 문제는 수정했습니다. 다만 요구된 반복 축에서 반대편 가장자리 색상은 모두 완전히 같지 않으며, 이음새 없는 최종 텍스처라고 인증하지 않습니다.

매니페스트의 seam_x/seam_y는 대응하는 반대편 끝 픽셀들의 premultiplied RGBA 차이입니다. 평균 차이는 0~255 척도이며 단독 합격 기준이 아닙니다. 실제 화면 배율에서 경계의 색·무늬·선의 연속성을 확인해야 합니다.

## 클로드에게 전달할 사항

1. tile-spec.json은 목표 규격이며 실제 파일 크기는 asset-manifest.json의 size를 사용하세요.
2. floor_edge와 garden_edge의 비율 보정을 먼저 처리하세요. 세로 길이를 목표에 맞춰 압축하면 그림이 변형되므로 확인 없이 완성 규격으로 간주하지 마세요.
3. 기둥 3조각의 홈 위치·너비·금색 선 연결, 울타리의 바닥 여백과 레일 위치를 개별 조정해야 합니다.
4. 타일 경계의 색상 및 무늬를 맞춘 뒤 반복 미리보기에서 검수하세요. 반복 옵션 지정만으로 기존 이음새가 제거되지는 않습니다.
5. floor_slab_a/b/c는 개별 돌판이므로 외곽 줄눈을 유지하세요. seamX/seamY가 false인 변에 무조건 심리스 처리를 적용하지 마세요.
