# Claude 작업 지시

`PROJECT_SPEC.md` v1.1과 이 폴더의 `README.md`를 읽고 온라인 그리스신화 스도쿠 게임을 구현해 주세요. 초3 아이와 성인이 함께 즐기는 가족 선물입니다. 스도쿠 → 별빛 → 가구 구매·꾸미기 → 가족 집 방문·방명록이 핵심입니다.

이번에 만든 쿼터뷰 배경 2장과 가구 20종은 `images/`에 실제로 있습니다. `asset-manifest.json`으로 로드하고 재생성하거나 임의 원격 이미지로 대체하지 마세요. 원본 https://github.com/Hunjeh404/greek-myth-map 에서 기존 인물·보물·이야기 자원을 재사용하되 기존 사이트 동작은 유지해 주세요. 새 게임 코드는 별도 프로젝트에서 작성하세요.

우선 배경 위에 가구를 올려 축소 크기·접지점·벽 방향·깊이 순서부터 보정하세요. 배치 초깃값을 최종 좌표로 오인하지 마세요. 바닥은 12×10 논리 격자이고 쿼터뷰입니다. 생성 그림은 완전한 2:1 타일셋이 아니므로 실제 바닥 폴리곤에 맞춥니다. 단일 방향 PNG이므로 가구 임의 회전은 비활성화합니다.

`interaction-spec.json`에 따라 물결·김·빛은 오버레이, 눌림은 작은 전체 스프라이트 변형, 책장·우편함·액자는 기능 화면 연결로 구현해 주세요. 원본이 단일 레이어이므로 상자 뚜껑 열림이나 모빌 별의 독립 운동을 구현했다고 주장하지 마세요. 등불은 켜짐 효과를 덧붙이고 방문자의 토글은 로컬에서만 유지하세요.

그다음 실제 로그인 → 스도쿠 완료 → 서버가 한 번만 보상 → 가구 구매 → 배치 저장 → 두 번째 계정의 집 방문 → 방명록 작성까지 연결하세요. 저장은 Supabase 등 온라인 DB에서 처리하고 GitHub에 사용자정보·진행상황을 커밋하지 마세요. RLS·서버 권한·재화 거래 검증과 중복 보상 방지를 구현하세요. 방문자는 집주인 데이터에 임의 쓰기를 할 수 없어야 합니다.

연결된 백엔드가 없으면 마이그레이션·환경변수 예시·실행 절차까지 준비하고 필요한 설정을 정확히 알려주세요. 로컬 목업을 온라인 완성으로 보고하지 마세요. 첫 세로 흐름을 완성한 뒤 기존 보물 10종, 여정·도감·작은 놀이를 확대하세요.

완료 시 코드, 마이그레이션, 보정된 매니페스트, 실행·배포 안내, 실제 검증 결과와 미완료 항목을 제공해 주세요.
