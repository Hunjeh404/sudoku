# 스도쿠 이어서 풀기 카드

`images/ui/resume_card.png`에 투명 배경 PNG 1장을 넣었습니다. 정면 구도, 꿀빛 나무 테두리, 금색 모서리, 왼쪽 청동 필기구·세이지 리본, 비어 있는 연한 라벤더 크림색 본문으로 제작했습니다. 원본 지시서와 가이드, 생성·수정 프롬프트, 검수 데이터를 함께 제공합니다.

## 검수 및 미완료 사항

- 실제 파일: **2172×724, 3:1, RGBA PNG**.
- 요청 파일: **1536×384, 4:1**. 수정 생성 후에도 캔버스 크기·비율은 충족하지 못했습니다.
- 투명도 범위: 0~255. 이미지 파일 디코딩 및 ZIP 무결성 확인 완료.
- alpha≥8 픽셀의 영역: x=6~2165, y=79~646. 위아래 투명 여백이 남아 있습니다. 이 범위는 장식의 바운딩 박스이며 확정 크롭 좌표가 아닙니다.
- 글자·숫자는 넣지 않았고 중앙과 오른쪽은 빈 밀랍 면입니다.
- 테두리 40px, 왼쪽 240px 장식 영역, 가로 늘림 경계의 정확한 좌표 정합은 미완료입니다.

## 적용 시

요청한 최종 규격으로 여백 정리와 크기 보정을 해야 합니다. 카드 전체를 가로로 늘리면 필기구와 모서리도 변형되므로, 왼쪽 장식과 양 끝을 고정하고 가운데 영역만 늘리는 방식을 사용하세요. 고정·늘림 영역의 좌표는 최종 규격 보정 후 결정해야 하며, 이 묶음에서 검증된 9-slice 좌표를 제공하지는 않습니다.

PNG는 생성 결과를 그대로 보존했습니다. 이전 가구·UI·타일 묶음 및 게임 코드는 포함하지 않습니다.
