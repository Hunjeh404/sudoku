# 올림포스 스도쿠 — 가구·UI 일러스트 26장

첨부된 두 제작 지시서에 따라 생성한 가구 20장과 스도쿠 UI 6장입니다.
**이미지 생성은 완료했지만, 정확한 픽셀 규격과 가이드 정합은 일부 미완료입니다. 게임에 바로 일괄 교체할 수 있는 최종 규격본으로 취급하지 마세요.** 자세한 차이는 `검수결과.md`를 확인하세요.

## 구성

- `images/furniture/`: 쿼터뷰 가구 20장, 모두 1254×1254 투명 PNG
- `images/ui/`: 테두리·금화·메모 동전·두루마리·돌판·배경 6장
- `guides/`, `guide-spec.json`: 제공받은 원본 배치 가이드
- `PROMPTS-furniture.md`, `PROMPTS-sudoku-ui.md`: 제공받은 제작 지시서 원문
- `asset-manifest.json`: 실제 크기·투명도·파일 해시·요청 좌표
- `generation-prompts.json`: 생성 프롬프트 및 채택한 수정 프롬프트
- `검수결과.md`: 확인 결과와 남은 수정 사항

## 클로드에게 전달할 작업 지시

먼저 검수결과와 매니페스트를 읽고 이미지를 미리보기 화면에 배치하세요. guide-spec의 좌표는 목표 좌표이며 이미지가 이미 그 좌표에 맞춰졌다는 의미가 아닙니다. 가구별 실제 바닥 접점을 확인한 다음 앵커·크기·회전 방향을 보정하세요. 이미지 전체의 바운딩 박스를 바닥 면적으로 간주하지 마세요. 정확한 기하 정합을 구현하려면 일부 이미지는 별도 편집 또는 재작화가 필요합니다.

UI는 실제 파일 크기를 기준으로 다루세요. 특히 board_frame의 중앙 투명 영역은 지시서 규격과 달라 별도 보정이 필요합니다. plaque는 종횡비도 달라 단순 비율 유지 축소만으로 목표 크기에 맞출 수 없습니다. 늘림용 경계 좌표는 미확정이므로 9-slice 값을 임의로 확정하지 마세요.
