# 검수결과

## 완료 범위

가구 20장과 UI 6장, 총 26장의 PNG를 생성했습니다. 모든 파일의 디코딩·개수·SHA-256을 확인했습니다. 가구 20장은 모두 1254×1254이며 투명 픽셀을 포함합니다. UI 중 배경은 불투명이고 나머지 5장은 투명 픽셀을 포함합니다. 투명 픽셀 존재 여부는 모든 내부 빈 공간이 올바르다는 보증이 아닙니다.

| 파일 | 요청 크기 | 실제 크기 | 크기 일치 |
|---|---:|---:|:---:|
| board_frame.png | 1254×1254 | 1254×1254 | 예 |
| coin_gold.png | 512×512 | 1254×1254 | 아니요 |
| coin_memo.png | 512×512 | 1254×1254 | 아니요 |

board_frame: 요청된 중앙 1004×1004 영역(x=125~1128, y=125~1128)에 불투명/반투명 픽셀이 209,306개 있어 중앙 개구부 규격을 충족하지 않습니다. 캔버스 크기만 일치합니다.

## 가구 정합

시각 검토에서 여러 가구의 크기·바닥 접점·기울기가 원본 가이드와 정확히 일치하지 않는 점을 확인했습니다. 가구 20장 모두 픽셀 단위 정합 합격 판정을 하지 않았으며, 배치 전 개별 확인 및 수정이 필요합니다. cloud_cushion과 display_pedestal은 크기를 줄이는 수정본을 채택했지만 목표 위치에 정확히 맞지는 않습니다.

guide-spec.json의 slope 0.65와 cornersPx/frontPx는 원본 목표값입니다. asset-manifest.json의 visibleBoundsAlphaAtLeast8은 실제 보이는 픽셀의 범위이며 바닥 접점 또는 충돌 영역이 아닙니다. 목표 좌표를 실측 앵커로 오해하지 마세요.

## 남은 작업

- 가구별 기준면·바닥 접점·화면 내 크기를 가이드와 맞추기. 방향이나 기하 구조가 다른 경우 별도 편집 또는 재작화 필요.
- 금화·메모 동전·두루마리·돌판·배경의 출력 크기 보정. 돌판은 비율과 늘림 구간도 재검토.
- 퍼즐판 테두리의 정확한 중앙 투명 영역과 대칭 보정.
- 지시서의 세부 장식·내부 빈 공간·정확한 9-slice 경계는 항목별 정밀 검수 미완료.

파일 손상 검사와 형식 검사는 완료했지만, 모든 미술·기하 요구사항을 충족했다는 의미는 아닙니다.
